# S3-08 Agent 预览确认与网页结果：实施记录

日期：2026-10-14
状态：S3-08 已完成（独立测试库验收通过，2026-10-14）；正式环境开关仍保持默认关闭。

## 做了什么

1. 增加物料入库、生产领料两种只读 Agent 预览工具。模型只可传准确单据编号或 ID；服务端用当前用户身份读取 Java 单据执行预览、权限和结果查询资格。编号查询要求单条且精确匹配。
2. 预览时把用户、动作、单据、完整预览摘要和 UUID 操作 ID 存入 SQLite。确认前重读并比对状态、版本、明细和库存位置；变化时关闭旧预览。两种动作各有独立开关，默认关闭。
3. 注册两种不向模型暴露的执行工具。网页确认只传操作 ID；服务端用绑定的单据和版本向固定 KTG 地址提交一次，然后查询 Java 持久回执。重复确认使用同一 ID；独立库测试已验证重启后可按原 ID 查询。未知结果不报成功。
4. 增加悬浮窗预览与结果卡，显示物料、数量、批次、来源和目标位置，执行时禁用重复点击。断线或刷新后查询同一回执；仅持久回执确认成功时通知对应单据列表刷新。
5. 增加配置说明与假 KTG 测试，覆盖两种单据、响应丢失后回查、明细变化拦截、重复确认、SQLite 存储对象重新实例化后的回查和用户隔离。

## 启用条件

须部署 S3-05～07 的 Java 执行、预览和持久回执接口，设置绝对路径 `AGENT_INVENTORY_DB`，再按需打开 `AGENT_ENABLE_ITEM_RECEIPT`、`AGENT_ENABLE_PRODUCTION_ISSUE`。页面账号除对应动作的编辑权限外，还需要对应单据的 `query` 权限与库存读取权限（现有菜单 `mes:wm:wmstock:list`，或已有的 `mes:wm:wmstock:query`），才能读取详细回执。真实验收需完成 07 所述独立库故障代理与跨进程重启，并记录当前用户权限、网页结果、数据库单据、库存、流水及回执核验结果。
