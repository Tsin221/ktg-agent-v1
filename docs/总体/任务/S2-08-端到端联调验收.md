## 任务

在独立测试库中联动 Java 后端、Python Agent 和 Vue 页面，逐项检查“创建草稿 → 生成 BOM → 回读 → 页面刷新”和“编辑草稿 → 必要时重建 BOM → 回读”。分别从原有工单页面和悬浮窗操作，确认两条路径遵守同一字段、状态、权限和事务规则。

测试故障包括：BOM 第二行写入失败、非法数量、同名产品、非草稿编辑、两个用户同时编辑、重复工单编号、批量删除混合状态，以及 Agent 写入后响应丢失。记录每个场景的接口响应和最终数据库状态。不得在生产库注入故障。
