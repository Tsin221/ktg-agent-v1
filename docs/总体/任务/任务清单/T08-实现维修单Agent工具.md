## 工具范围

优先使用与现有工具一致的 `ktg_dv_repair_*` / `ktg_preview_dv_repair_*` 命名，最终名称和数量由 Sol 根据注册约定落实并记录。

### 查询工具

1. 维修单分页查询：业务编号、名称、设备编码/名称、维修结果和单据状态等实际支持筛选。
2. 维修单详情：明确 ID 或准确业务编号定位，缺失或多命中给出清晰错误，不自动挑选。
3. 指定维修单的维修内容分页查询，必须校验返回记录归属，不允许漏传父 ID 而查询全部。
4. 维修相关选项/字典：展示真实状态、维修结果及本批工具支持的动作边界。
5. 新增/编辑所需设备和项目候选查询；可复用现有工具或以维修语境提供专门入口，避免重复实现无业务价值的工具。

### 写预览与可信确认执行

覆盖单个草稿维修单的新增、修改、删除，以及所属维修内容行的新增、修改、删除。

- 模型可发起预览；真正执行只经现有可信确认通道，不向模型开放可直接执行的 apply 工具。
- 预览展示可读的业务编号、对象、修改前后及删除影响；绑定用户身份、动作、内容摘要、有效期和持久化预览记录。
- 确认时复核身份、权限、预览内容和当前业务状态；同一预览重复确认使用已有回执；未知结果不得自动重复提交非幂等写入。
- 主表写入限定草稿允许字段，不接受客户端伪造状态、审计字段、人员字段或额外属性。更新须保留未修改字段。
- 子表写入验证父单 ID 与记录归属，并由真实候选信息生成设备/项目快照，不信任模型伪造的名称、编码或源对象快照。
- 删除预览须说明关联维修内容的处理；如复用后端删除流程，确保父子处理原子一致、不产生孤儿记录。仅靠 Agent 预读不能替代后端状态和归属守卫。
- Sol 先核对已有后端保障，必要时最小补齐事务、状态、归属或删除守卫及对应隔离测试；不得扩展为通用状态机重写。
