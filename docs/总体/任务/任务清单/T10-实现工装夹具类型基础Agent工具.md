## 基础工具范围

建议采用`ktg_tm_tooltype_*`和`ktg_preview_tm_tooltype_*`命名，归属`tm/tooltype`。实际名称须在完成文档列出。

| 能力 | 范围 |
| --- | --- |
| 类型列表 | 类型编码精确、名称模糊、维护类型等真实接口支持筛选，分页有上限，说明本页数量与总数。 |
| 类型详情 | 根据明确ID或精确编码读取；不存在或多命中时给清晰错误，不按名称猜测对象。 |
| 基础选项 | 是否编码管理、维护类型、周期范围及单位，采用真实字典/页面规则，不提供无意义副作用“选项”。 |
| 新增预览与确认 | 明确业务编码、名称、编码管理开关和所需维护字段，生成预览后由网页确认保存。 |
| 修改预览与确认 | 精确定位单个对象，仅更改用户明确指定字段，保留未修改字段；显示修改前后。 |
| 删除预览与确认 | 精确定位单个类型，展示业务编码及名称；确认后删除并回读核实，不做批量删除。 |

业务能力为6项。按现有架构可分为3个查询、3个模型可见写预览、3个模型不可见确认执行定义，不为数量增加其他工具。不扩展工装台账写入、保养执行、复杂流程、导入导出或批量操作。

## 业务与参数约束

- 类型编码不超过64字符，名称不超过100字符，备注遵循页面250字符限制；明确文本空值/清空语义。
- 编码管理为`Y`时，维护类型只能`REGULAR`或`USAGE`，周期为1至2147483647的整数，拒绝布尔值、空、0、负数、小数及溢出。
- 编码管理为`N`时，不适用的维护类型和周期规范化为空，显示“无”；从N改为Y须提供合法维护设置。
- 更新保持现有后端完整PUT语义：先读取可信原记录、合并白名单变更、复核后再发送，不把未提供字段误清空。不接受模型提供的主键覆盖、审计字段或额外属性。
- 新增要求用户给明确编码；不调用会消耗流水的自动编号接口，不把编号生成伪装为只读查询。
- 保留编码/名称唯一性检查及后端错误反馈。历史异常值可查询展示，不猜测修复。
- 删除前及确认时检查关联工装台账，存在引用时提示并拒绝工具删除，不修改或级联删除台账；使用真实接口和对应读取权限。预读不被表述为后端事务锁或全局并发保障，不为此扩展复杂业务系统。

## 确认、权限与持久性

- 模型只生成预览，执行工具不能在模型通道调用或发现；网页确认经现有可信通道，服务端重新校验当前身份和MES权限。
- 预览绑定用户、动作、内容摘要、有效期和原记录快照，并持久保存。确认时拒绝过期、篡改、快照变化或权限变化。
- 重复确认复用回执，非幂等请求不得自动重试；发送后超时或回读无法确认时标为UNKNOWN，不自动重复写入。
- 读工具使用真实`mes:tm:tooltype:list/query`权限；写工具使用对应add/edit/remove及必要的读取权限，关联台账检查另需`mes:tm:tool:list`。不扩大角色权限、不使用管理员后门身份。
- 沿用模块/工具开关与独立SQLite预览库，默认写入配置关闭。独立绝对库路径不得与已有会话或其他预览库共用。
- 接入现有目录/搜索/加载/QueryService/Server确认接口与配置示例，不能只有孤立函数。确保默认模块开关包含新工具所需的tm模块。

## 页面集成

- 为列表、详情、选项、写预览及执行结果提供简明中文卡片，可复用当前样式与组件组织。
- 预览能看清目标、修改前后、周期单位与删除影响；确认中、已确认禁用按钮，失败或UNKNOWN不显示成成功。
- 经确认且回读核实成功后刷新当前类型列表；若当前打开对象被删除则关闭，避免异步回读覆盖用户已切换的对象；销毁时清理监听。
- 不改变已有设备工具的卡片、确认入口与默认配置行为。
