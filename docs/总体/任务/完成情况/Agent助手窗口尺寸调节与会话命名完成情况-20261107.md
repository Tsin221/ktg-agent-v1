## 根因及实现

原助手面板桌面固定390px宽、最高620px，没有调整入口。新会话按钮直接创建默认名称，会话创建接口虽接收title，但缺少历史名称更新接口。

1. 桌面面板左上角增加可发现的双向拖拽按钮，向左/上拖动扩大宽/高；也可聚焦后使用方向键，每次20px。正常最小360×420，最大为视口宽/高减48px；视口更小时优先服从视口上限。消息区域可收缩并滚动，输入框允许收缩。600px及以下保持全屏布局并隐藏拖拽入口。
2. 尺寸保存在localStorage的ktg-agent-panel-size。关闭重开及新实例挂载恢复偏好；非法JSON、非有限数值、负值或存储不可用回退390×620默认值。视口临时缩小时显示尺寸受限，原偏好仍保留。拖拽结束、关闭、视口变化和销毁均清理拖拽监听，销毁同时移除窗口resize监听。
3. 新会话改为面板内名称表单，可空名保存以保留原默认行为；历史会话可重命名。支持保存、取消和Esc，保存中防重复提交并禁用重新打开编辑入口，失败显示错误且不伪造标题。
4. 标题trim后1至200个Unicode字符，创建可不传title；前端使用Unicode码点计数，与Python一致，200个字符含中文和emoji均可保存。SQLite原字段为TEXT无长度约束，本次统一增加200字符应用上限，无数据库迁移，已有历史标题不改写。
5. 新增POST /agent-api/v1/sessions/{session_id}/title，只接受{title: string}，成功200并返回session_id/title/created_at/updated_at。沿用当前登录身份查询、敏感内容过滤、参数化SQL，更新条件同时包含会话ID和owner_user_id；越权/不存在404、身份失效401、格式错误400。更新title及updated_at持久化SQLite。新建与重命名共用标题校验。
6. 名称异步保存使用请求序号、会话epoch、会话ID隔离。切换会话或身份变化不让旧结果覆盖新状态；重新读取会话时也更新列表中的服务端标题。
