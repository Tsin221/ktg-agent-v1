## 交付能力

接入现有 Agent 工具目录、权限校验、持久化预览和网页可信确认链路，提供六项业务能力。写操作模型只能生成预览，三个执行定义不向模型公开。

| 能力 | 工具定义 | MES 权限 |
| --- | --- | --- |
| 台账分页查询 | `ktg_tm_tool_list` | `mes:tm:tool:list` |
| 台账详情 | `ktg_tm_tool_detail` | `mes:tm:tool:query`、`mes:tm:tool:list` |
| 基础选项 | `ktg_tm_tool_options` | `mes:tm:tooltype:list` |
| 新增预览 / 确认执行 | `ktg_preview_tm_tool_create` / `ktg_tm_tool_create` | `mes:tm:tool:add`、`mes:tm:tool:list`、`mes:tm:tooltype:query` |
| 修改预览 / 确认执行 | `ktg_preview_tm_tool_update` / `ktg_tm_tool_update` | `mes:tm:tool:edit`、`mes:tm:tool:query`、`mes:tm:tooltype:query` |
| 删除预览 / 确认执行 | `ktg_preview_tm_tool_delete` / `ktg_tm_tool_delete` | `mes:tm:tool:remove`、`mes:tm:tool:query`、`mes:tm:tooltype:query` |

写入确认通过 `POST /agent-api/v1/tm-tool/confirm`；服务端再调用对应 MES 写接口并回读核验。工具目录模块为 `tm`、域为 `tool`。前端提供查询、选项、详情、预览和结果卡片；只在回读成功且 `verified=true` 时刷新台账。卡片展示修正后，合法数量 `0` 显示为 `0`。

## 业务和安全边界

- 新增需明确业务编码、名称和类型 ID；类型编码、名称及 `codeFlag` 从 MES 类型接口读取。独立编码类型数量固定为 1；非独立编码数量为 0 至 99,999,999 的整数。
- 新增维护字段可省略并保持为空。`REGULAR` 可带合法日期；`USAGE` 可不带周期，提供周期时必须为 1 至 2,147,483,647 的整数。非适用字段拒绝或按维护方式切换规则清空。修改仅接收名称、品牌、型号、维护方式、下次保养日期/周期及备注；未传字段保留原值，显式空值可清除。
- 删除只接受在库且数量等于可用数量的可信记录。工具不开放编码自动生成、状态变更、领用归还、批量操作、导入导出或保养执行。
- 预览绑定用户、动作、输入摘要、TTL 和原记录/类型快照，存入独立 SQLite。确认时重新校验权限、身份、快照和业务条件。执行工具在模型侧隐藏，写入不自动重试；无法确定回读结果时返回 `UNKNOWN`，不触发成功刷新。
