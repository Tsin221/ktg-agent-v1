## 迁移、权限、清理和部署交接

- 独立库已存在 S3-02～05 迁移所需列及唯一索引：回执 `operation_id` 主键、单据执行三列主键、流水关联唯一键、库存 `stock_dimension_key` 唯一键。本轮未向默认数据库运行迁移脚本。正式环境先备份并执行 `s3-04-stock-preflight.sql` 及 S3-02 的历史流水只读检查，再依 `scripts/apply-db-migrations.ps1` 所列顺序迁移目标库，核对索引、版本列和业务数据，随后部署对应 Java、Agent、Vue 构建。
- 操作员最小权限：入库需要 `mes:wm:itemrecpt:query/edit` 与 `mes:wm:wmstock:list`；领料需要 `mes:wm:issueheader:query/edit` 与 `mes:wm:wmstock:list`。未授权用户必须在写入前收到 403；回执只对原执行人可见。网页悬浮窗另受当前登录身份、预览版本和独立动作开关保护。
- 本轮临时用户/角色 12～14 均 `del_flag=2`，用户角色及角色菜单关联数均为 0。首次失败网页尝试产生的空 Agent SQLite 已移除；后续成功模型操作的绑定和回读结果保留在 `.runtime/s309-agent-approved.sqlite3`，需与 Java 回执一并保存。已执行单据、库存流水、成功/失败回执和关联数据继续保留，维持审计链；未单独删除执行后的夹具。本次未归档或整体清理专用验收库。
- 回滚应用代码时保留新表与已执行数据；不能删除回执后让旧入口重新记账。若出现迁移或代码问题，先关闭对应动作开关并保留原操作 ID，回退到兼容代码或经核验的整库快照。不得仅删除某张已执行单据或其流水。
- 正式环境的 `AGENT_ENABLE_ITEM_RECEIPT`、`AGENT_ENABLE_PRODUCTION_ISSUE` 均保持关闭。两个动作的独立环境验收均已通过，具备分动作开放的验收依据；正式部署前仍须按动作单独批准开关，核验迁移、最小权限和第一笔受控交易。当前状态为“独立环境验收通过／正式环境未部署”。
