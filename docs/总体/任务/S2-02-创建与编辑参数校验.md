## 任务

当前 Controller 直接接收 `ProWorkorder`，Mapper 允许请求影响 `status`、`quantityProduced`、`createBy` 等字段；编辑接口还会在写入后读取请求中的产品 ID 和数量比较。新增专用请求对象或等效边界，只接受本阶段允许写入的字段。决定编辑语义：推荐明确的草稿完整编辑契约；若支持备注等部分编辑，则必须在读取现有工单后合并并校验，不能先写后因空值报错。

校验工单 ID/编号、产品 ID、产品存在性、正数数量、业务日期、字段长度和父级引用。产品编码、名称、单位由服务端根据产品 ID 查得或核实，不信任客户端自由填写的副本。创建人、更新时间及草稿状态由服务端设置。业务错误在数据库写入前返回可读的字段错误码。

## 原验收标准（立项清单）

- [ ] 缺失产品、数量不大于零、非法日期、超长字段和不存在的工单均在写入前拒绝。
- [ ] 客户端传入 `status`、已生产数量、创建人等非草稿编辑字段时，按契约明确拒绝或忽略，并有测试覆盖。
- [ ] “只改备注”按选定契约成功，或在数据库未变更前明确返回参数错误；不能出现接口失败但数据已变化。
- [ ] 产品名称、编码和单位由服务端与产品 ID 保持一致。
